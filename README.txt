MOHIT SAHU PORTFOLIO
=====================

Files:
- index.html  -> main website
- style.css   -> design and responsive layout
- script.js   -> animations and mobile menu
- profile.jpg -> profile photo
- certificate-*.jpg -> certificate images

HOW TO USE:
1. Keep all files in the same folder.
2. Open index.html in a browser to preview.
3. To publish it online, upload the folder to a static hosting service such as GitHub Pages.

EDITING:
- Change text/links in index.html.
- Change colors and layout in style.css.
- Replace profile.jpg or certificate images if needed.
